# Exercise glossary: one word per thing

Every student-facing string uses the word in the first column and nothing
else for that thing. The third column lists words that mean the same thing
and must be replaced.

| Use this | Means | Never on a student screen |
|---|---|---|
| **Round 1** / **Round 2** | The two exercise events, in order. Round 1 is Northline, Round 2 is Harbor. Banner form: "Round 1 of 2: Northline". | Step, stage, phase, round one / round two (spelled out), Session 1 / Session 2 (that is the class meeting, not the round) |
| **Northline** / **Harbor** | The events, by short name. Full name only where the event is introduced. | event A/B, first event / second event |
| **setting** | A named set of the four slider numbers a team saves ("Major first", "Balanced"). | weights (as a noun for the saved thing), slot, preset, configuration, strategy |
| **slider numbers** | The four numbers at the top of the event page. | factors, weights vector, coefficients |
| **list** | The 60 students a setting picks for CBACH to email. | ranking, ranked list, shortlist, matches, invitees (on the event page) |
| **results run** | The team's one press that sends a list and shows results. One per event. | run, simulation, draw, attempt |
| **card** | The profile card a student completes when asked for more. | profile update, survey, form |
| **mass email** | The one email sent to all 300 students. | blast, broadcast, baseline |
| **CBACH emails** | The tailored, personalized emails CBACH sends to the team's list. | invitations, your invites, outreach |
| **how much we know** | How complete a student's card is (the "by how much we know" table). | profile completeness, data quality, coverage, information level |
| **asking for more** | Round 2's first part: promise, small reward or required. | refresh, profile refresh, data collection |
| **stopped responding** | Asked under "required", the student stops opening messages and will not sign up for anything, mass email included. Always say this in plain words next to the number. | churned, opted out, dropped |
| **signed up** / **came** | Sign-up, then attendance (65% of sign-ups come). Say which. | added (alone, without saying added what), converted |

## Never in student copy (internal words)

slot (except Ann's verbatim "Empty. Save a setting to fill this slot."), workspace,
factor, refresh, sequence, cap, payload, server, fixture, data file / dataset (instructor page only),
ranked / ranking (say "on the list"), profiles (say "students"), invitations (say "CBACH emails"),
"the model", "the algorithm". `--banned` fails on the first six; the rest are warn rows to read.

## Numbers

- Every number names its unit: "60 students", "7 extra sign-ups", "4 of them came".
- The same quantity has the same number and the same words on every screen that shows it.
- List size is read from the server, never typed into copy ("60" today, was "30").
