## 5. Decision gates

1. **Additive vs bump:** additive `teams` array, legacy fields kept — recommended. No external contract version to bump (exercise surface absent from `smartmatch.json`; models are the contract, `exerciseClient.ts:1–25`), and additive keeps `:338–424` green per the issue's own acceptance.
2. **Enumerate all existing teams vs all numbers 1–6:** recommend existing workspaces only — `list_team_workspaces` already treats a never-entered team as *absent, not invented* (`exercise_instructor.py:480–483`). If Ann literally wants six lines, add outcome `not_entered` synthesised over `EXERCISE_TEAM_NUMBERS` — cheap, but it reports teams that were never asked anything. Flag to product.
3. **`skipped` semantics:** keep legacy meaning (chosen-but-failed) next to `teams`; do not redefine as "all non-refreshed" or the pinned tests move.
4. **`dataset_label` per team:** include only if the new read joins `exercise_dataset` (instructor repo does this; results repo does not). Worth it for the split-file case — refresh-all is deliberately cross-dataset and two "Team 3"s otherwise collide. Never `dataset_id` (forbidden field on this track's models).
5. **Counts on already-refreshed teams:** costs a `list_team_profiles` per team via `refresh_counts_from_view` (`exercise_results_refresh.py:177–193`); recommend `null` on skips — the Teams panel already shows "Has already asked."
6. **Reason-code set:** `no_asking_choice | no_round_one_run | already_refreshed` (+ `not_entered` only if gate 2 goes that way). CBA precedent names it `status`/`skip_reason` (`api.ts:3122–3133`); the issue's `outcome`/`reason_code` is clearer here.
7. **Label copy:** recommend "Refresh every team that has chosen how to ask" — verbatim the route summary, already Ann-consistent; all final strings go through §11.1 regardless.

## 8. Risks

- **Partial failure mid-loop:** unreachable by design — one transaction, one commit (`:141`); a refused write 409s the whole request and nothing reports. Do not add per-team "failed" outcomes; they cannot occur.
- **Mislabeled race-skip:** claim-lost (`applied is None`) must be classified by re-reading `team_state`, not lumped into `no_round_one_run`.
- **Ordering drift:** `workspaces_awaiting_refresh` sorts by `dataset_id`; the Teams panel sorts by `uploaded_at` — a report in uuid order reads wrong in a two-file class. Order the new read to match the screen.
- **Field-name trips:** `dataset_id`, `seed`, and any `score/percent/share`-shaped name fail the contract walks instantly.
- **Denominator trap:** "12 of 22" requires the no-card invited count, currently internal to `refresh_plan`'s call — expose it deliberately (shared with #329) rather than recomputing differently in two places.
- **File ceilings:** `exercise_instructor_refresh.py` has headroom; if a new module is introduced, it must be added to `_TRACK_MODULES` (support.py:89–96) and both pyproject import-linter lists (`pyproject.toml:309–335, 395–421`) or `make imports` fails.
