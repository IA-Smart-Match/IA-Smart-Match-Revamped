## 3. Architecture decision the planner must make

`workbook.py`'s contract is "nothing here knows a column name" (module docstring ~:4); `layout.py` is the single source of names, and `test_no_function_writes_a_column_or_sheet_name_down` (AST test, `test_exercise_ingest.py`) enforces it. Hard-coding `{"event_description": 2000}` in `workbook.py` violates that. Recommended shape:

1. `workbook.read_sheets(raw, sheet_names, *, cell_limits: Mapping[str,int] | None = None)` — limits keyed by **normalized heading**, applied to body cells only; headings keep 500.
2. `layout.py` gets `event_description_column` + a declared-limits map (e.g. `CELL_CHARACTER_LIMITS = {"event_description": 2_000}`) so ingest passes layout data, not a literal.
3. `ParsedEvent` gains `description`/`event_description` — this is #318's field; #325 should add the layout/cap seam but coordinate so #318 owns storage/display plumbing.
