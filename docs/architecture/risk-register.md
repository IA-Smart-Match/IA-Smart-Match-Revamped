# Architecture Risk Register

**Stage 1 §14.** Commit `c72dced`, 2026-09-08.

**Priorities:**
- **P0** — correctness, security, data-loss, or release blocker.
- **P1** — architectural debt actively obstructing implementation.
- **P2** — debt likely to compound during upcoming development.
- **P3** — improvement with limited near-term impact.

**Probability / Impact / Urgency** are the auditor's judgement; **Evidence** is
repository fact.
