# Smart Match CPP — clickable prototype (Oct 6, 2026)

**What this is:** a clickable design of where Smart Match is heading, for the CBACH advisory board presentation on Thursday, Oct 8. It shows the screens only. Nothing is saved, and it is not connected to any database.

**How to open it:** download `SmartMatch_CPP_Prototype_10062026.html` and double-click it. It opens in Chrome or any browser, with no internet needed except for the fonts.

**How to rehearse:** click "Presenter guide" in the bottom-right corner. It shows, for each screen, who presents, what to click, and one line to say.
- Chau: Student interview, Events for me, Match students to an event, Partner portal
- Janice: My readiness, My growth, Career Hub overview and student records

## What's real and what's made up
- **From our class file (300 made-up students):** Grace Delgado (P046), all student records, the matching, and the Career Hub overview counts.
- **Made up for the demo:** the three fall events, the partner's talk numbers, the readiness numbers for the 300, the appointment times and the resource names.
- **Scripted, not live AI:** the profile interview and the CBACH assistant bot. Please say this out loud when presenting.
- **Draft:** the six readiness markers. They will follow the college's official Career Success Markers.

## Rules
- Present it as our design for the next phase, not as finished software.
- Never put real student names or records into it.
- Each screen keeps its "working / planned" label until it runs on real data.

## Using it as the starting point for the real build
The page's code includes the layout, wording and matching logic (the same four factors and default weights 3/3/2/2). Build the real version to match these screens, one workflow at a time, starting with student records, CPP login and matching students to one event. The real build starts after the teaching module is finished (Oct 30), and only once the college gives the go-ahead.
