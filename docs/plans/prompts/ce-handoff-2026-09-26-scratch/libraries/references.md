# Design references — "playful but credible academic game"

No real-student imagery in any of these; borrow layout, motion and color logic only.

1. **Kahoot!** (kahoot.com) — Borrow: large-type, projector-readable question/result screens with bold flat color blocks per option; a classroom-safe playful palette that still reads as "official" enough for a professor to run live.
2. **Duolingo** (duolingo.com) — Borrow: the reward-moment pattern (confetti-adjacent, `canvas-confetti` already installed) tied to a specific milestone, not overused; progress ring/streak counter style for a "round 1 → round 2" indicator.
3. **Duolingo gamified progress UI, Dribbble shot** (https://dribbble.com/shots/27432803-Duolingo-Gamified-Learning-Progress-UI) — Borrow: card-based progress modules with soft shadows and single-accent-color badges, good reference for the saved-settings cards.
4. **Notion** (notion.so) — Borrow: calm, high-contrast neutral surface with a single accent color reserved for interactive/primary actions — a model for keeping the CPP green/gold restrained rather than everywhere.
5. **Linear** (linear.app) — Borrow: crisp micro-interactions (hover states, subtle spring-based list reordering) that feel premium without being playful-childish — a tone reference for the ranked-list motion.
6. **Stripe Docs / Stripe.com marketing pages** (stripe.com) — Borrow: confident use of whitespace and large numerals for stat displays — a reference for the seat-count / sign-up numbers on the results screen.
7. **Untools** (untools.co) — Borrow: clean diagram/framework visual language (simple line icons, generous spacing) appropriate for a "how matching works" explainer without looking like a corporate BI tool.
8. **Gather.town** (gather.town) — Borrow: friendly, illustrated, low-saturation spot art style for empty states and onboarding — closest tonal match for "playful but credible" spot illustrations like the ones authored in `assets/`.
9. **Class Dojo** (classdojo.com) — Borrow: classroom-safe, warm illustration style and reward iconography aimed at an academic (not consumer-gamer) audience — useful ceiling for how playful to go without tipping into "kids' app."
10. **Figma Community — "Dashboard UI Kit" style boards** (figma.com/community, search "education dashboard") — Borrow: card-grid layouts for comparing two saved settings side by side; generic reference, not a specific licensed file to copy.
11. **Material Design 3 — Data visualization guidelines** (m3.material.io/styles/color/data-visualization) — Borrow: their accessible categorical/sequential palette construction method, directly applicable to the results bar chart's must-be-colorblind-safe requirement.
12. **Polychat blog — Gamification examples in education 2026** (https://www.polychatapp.com/blog/gamification-examples-in-education) — Borrow: a survey of what reads as credible-academic gamification vs. consumer-app gamification, useful as a sanity check against going too playful for a college marketing course.

Sources found via web search: [Duolingo — Gamified Learning Progress UI](https://dribbble.com/shots/27432803-Duolingo-Gamified-Learning-Progress-UI), [10 Powerful Gamification Examples in Education for 2026](https://www.polychatapp.com/blog/gamification-examples-in-education).
